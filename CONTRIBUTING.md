# Contributing

Thanks for helping. You don't need to write code to contribute.

## Ways to help
- **Code**: pick an issue labelled `good first issue`.
- **Compliance data**: add or verify a jurisdiction checklist in `jurisdictions/`.
- **Docs and UX**: improve clarity for non-technical volunteers.
- **Review**: privacy, security and accessibility reviews are especially valuable.

## Process
1. Open an issue before large changes.
2. Fork, branch (`feat/...`, `fix/...`, `docs/...`), and open a pull request.
3. Keep PRs small and focused; fill in the PR template.
4. Never commit real personal data. Use synthetic data only.

## Compliance contributions
Every checklist item must include an official `source` URL and a `last_verified` date. Items without a source will not be merged.

## Conduct
This project follows the Contributor Covenant 2.1: https://www.contributor-covenant.org/version/2/1/code_of_conduct/ (see CODE_OF_CONDUCT.md).
